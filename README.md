# ar_app

Flutter AR app with 3D duck placement and gesture controls.

This app is a blueprint on how to create an AR app using a .glb file taken from github. 

## Features

- 📱 AR camera access on physical devices
- 🦆 Single duck placement per tap
- 🔄 Rotation and movement gestures  
- 📏 Vertical zoom slider for size control
- 🎯 Clean, simple AR experience

## Resources used to create this:

1. [banuba face AR app tutorial](https://www.banuba.com/blog/flutter-ar-guide)
2. [github 3D models](https://github.com/KhronosGroup/glTF-Sample-Models/tree/main/2.0/Duck/glTF-Binary)
3. [pub.dev](https://pub.dev)

## How to use:

1. Tap "Access Camera" to open AR view
2. Tap on surfaces to place a duck
3. Use the vertical slider to zoom in/out
4. Use gestures to rotate and move the duck

Built with Flutter and ar_flutter_plugin for iOS ARKit integration.
